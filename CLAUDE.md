# Instruktioner til Claude

Dette repo er **offentligt** og udgives med GitHub Pages. Det indeholder kun den krypterede udgave af stamtræsiden (`index.html`, lavet med StatiCrypt).

- Ret **ikke** i `index.html` her. Kilden og hele opsætningen (ukrypterede sider, kryptering, regler for indholdet) ligger i det private repo **`JanLangeDK/familyprivate`**. Tilføj det til sessionen og læs dets `CLAUDE.md`, før der ændres noget.
- Læg aldrig ukrypterede sider, dokumenter, billeder af familiepapirer, kodeord eller andet privat materiale i dette repo.
- Skriv til Jan på dansk.
